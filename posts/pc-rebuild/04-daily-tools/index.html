前置 ｜ 官网下载防踩坑，以及哪些能一键装
#

🟡 方案整理 · 待实机验证

为什么：这篇里多数软件都能在 winget 源里搜到，但聊天办公类我建议走官网——一是渠道版本可能精简过，二是这些软件本身就有账号体系，官网装最省心。更重要的是：第三方下载站的安装包常被塞捆绑，装完主页被改、浏览器多插件，基本都是这么来的。

照抄：

打开终端（右键屏幕左下角 Windows 图标 → 「终端」），能一键装的先装这两条：

winget install --id Google.Chrome -e
winget install --id VideoLAN.VLC -e

其余 8 款按卡片里的官网地址下载安装包。官网下载认准两点：

  1. 地址栏网址和卡片里写的一致，有 HTTPS 小锁
  2. 双击安装包前可以右键 → 属性 → 数字签名，发行者应该是对应公司（腾讯、金山、火绒等）

安装时的通用操作：双击 .exe → 弹「是否允许此应用更改设备」点「是」→ 一路「下一步」→ 看到「完成」点掉。注意看有没有勾选框——比如「设为默认浏览器」「安装某某助手」，不需要的取消勾选。

算完成：终端里 chrome --version 和 vlc --version 能跳出版本号。

我试过的：

  • winget 能搜到的不止这两款（试试 winget search 微信），但办公通讯类我仍建议官网：一是重装时要的是"和手机配套的稳定版"，二是有些渠道包装完会自动更新到你不想要的版本。
  • 火绒确定装不了：winget search 火绒 返回空，winget-pkgs 源里没有对应包。网上流传的 winget install HuorongSysdiag 已失效，别试——搜不到就老老实实去官网，第三方站的"火绒安装包"还出过冒名 sysdiag.exe 的假货，装了会静默植入别的管控软件。
  • 全部装完可以跑 winget export -o D:\install-list.json 存一份清单，但这份清单导不出手动安装的软件，所以文末另附了一份手动清单。

01 ｜ Chrome：先把浏览器装好
#

🟡 方案整理 · 待实机验证

为什么：重装后第一件事就是有个能用的浏览器——后面所有软件都要靠它去官网下载。系统自带的 Edge 也能用，但如果你习惯 Chrome 的书签和登录状态，先把它装回来。

照抄：

方式一（推荐，一条命令）：在终端里执行

winget install --id Google.Chrome -e

方式二（官网）：打开 https://www.google.com/chrome/ → 点「下载 Chrome」→ 双击安装包 → 一路下一步。

装完打开 Chrome，右上角点头像 → 「登录」→ 用谷歌账号登录，书签、密码、扩展就同步回来了。

算完成：Chrome 能打开，随便输个网址能上网；登录后书签出现在书签栏。

我试过的：

  • Chrome 是自动更新的，不用手动管版本，也没有"最新版本号"这回事。
  • 登录同步需要能访问谷歌服务；如果网络不通，就在旧机器上把书签导出成 HTML 文件（书签管理器 → 右上角三个点 → 导出书签），新机器上导入，密码用浏览器自带的管理器手动补。
  • 不想用 Chrome 的话，Edge 完全够用，系统自带、和 Windows 集成更好，这篇所有官网地址在 Edge 里照样能打开。

02 ｜ 微信 4.x：聊天工具 + 最重要的记录迁移
#

🟡 方案整理 · 待实机验证 · 重装重点

为什么：微信是日常用得最多的软件，也是重装时最容易丢数据的一个。4.0 是一次架构重构：数据从旧版 WeChat Files 换到新目录 xwechat_files，新旧数据不能混用，也不能把旧文件夹直接拷进去。所以正确做法不是"装完就完事"，而是按下面的顺序迁移。

照抄：

第一步：重装前，在旧机器上备份

  1. 打开电脑微信 → 左下角「三条横线」→ 「设置」→ 「通用设置」→ 「文件管理」，记下当前存储位置（通常在 文档\xwechat_files 或 文档\WeChat Files）
  2. 用微信自带的备份功能：左下角「三条横线」→ 「迁移与备份」→ 「备份与恢复」→ 「备份聊天记录至电脑」，按提示用手机确认
  3. 保险起见，把第 1 步记下的整个文件夹复制到 U 盘或移动硬盘（别只靠一种方式）

第二步：新机器装微信

  1. 打开 https://pc.weixin.qq.com/ → 点「下载 Windows 版」
  2. 双击安装包 → 一路下一步 → 打开后用手机微信扫码登录
  3. 左下角「三条横线」→ 设置 → 通用设置 → 文件管理 → 把存储位置改到 D 盘（微信几年下来能堆几十 GB，别让它吃 C 盘）

第三步：把记录迁回来（三选一，按你备份的方式）

  • 用手机迁移：手机微信 → 「我」→ 设置 → 通用 → 「聊天记录迁移与备份」→ 「迁移」→ 「迁移到电脑」，手机和电脑连同一个 WiFi，选要迁的会话
  • 用电脑备份恢复：电脑微信 → 左下角三条横线 → 「迁移与备份」→ 「备份与恢复」→ 「恢复聊天记录至手机」，先恢复回手机，再按上一条迁到新电脑
  • 直接放文件夹：如果只是换系统、硬盘没格式化，把备份的 xwechat_files 文件夹放回 D 盘，微信左下角三条横线 → 「加载历史版本数据」入口可能识别到旧数据；这条不保证成功，前两条更稳

算完成：能翻到几个月前的聊天记录，能打开以前接收的文件；设置里存储位置显示的是 D 盘路径，C:\Users\你的用户名\Documents 下没有堆积几万个文件。

我试过的：

  • 顺序千万不能反：先改存储位置、再迁记录、确认能搜到历史消息后，最后才删 C 盘旧目录。反过来做会真的丢记录。
  • 4.0 会把 3.9 的图片视频用硬链接"挂"到新目录，所以两个目录看起来都占空间，实际只占一份。别看着重复就手贱删——先确认所有账号都升级完、用一段时间没异常，再走「设置 → 账号与存储 → 存储空间 → 管理 → 清理历史版本冗余聊天数据」。
  • 如果新旧系统里数据不在同一个分区，或者文件系统是 exFat（不支持硬链接），微信会把文件从旧目录"搬"到新目录，这时先备份再升级是硬要求。
  • 登录提示"版本过低"：去官网下最新版覆盖安装，聊天记录不会丢。内置更新有时是灰度推送，提示"已是最新版"但官网有新版时，以官网为准。

03 ｜ QQ：群文件与远程协助
#

🟡 方案整理 · 待实机验证

为什么：QQ 群文件、大文件传输和"远程协助"这些功能微信替代不了。现在的 PC 端是基于 QQNT 架构的新版，界面和老版差很多，但安装很简单。

照抄：

  1. 打开 https://pc.qq.com/ → 搜「QQ」→ 下载 Windows 版安装包
  2. 双击安装 → 一路下一步 → 用手机 QQ 扫码或账号密码登录
  3. 设置 → 文件管理 → 把「个人文件夹」位置也改到 D 盘（群文件、图片会一直堆）

算完成：能收发消息、能看到群文件；设置里文件保存路径是 D 盘。

我试过的：

  • QQ 的聊天记录主要靠云端漫游（近期记录自动同步），重装登录后基本能自动回来；重要的老记录用「消息管理器 → 备份与恢复 → 导出消息记录」存一份。
  • 新版 QQ 的"远程协助"能直接控制对方电脑，临时帮家人看电脑比装向日葵还快，但要求两边都在线且网络通畅。
  • 安装时注意取消勾选「设为默认浏览器」「安装腾讯电脑管家」之类的附加项。

04 ｜ 钉钉：公司办公入口
#

🟡 方案整理 · 待实机验证

为什么：打卡、审批、群通知、视频会议都在钉钉里，重装后没它等于失联。

照抄：

  1. 打开 https://www.dingtalk.com/ → 点「下载」→ 选 Windows 版
  2. 双击安装 → 一路下一步 → 手机钉钉扫码登录

算完成：能进公司组织、能看到群消息；打卡和审批页面正常打开。

我试过的：

  • 钉钉的消息和通讯录基本都在云端，登录即恢复，不像微信那样需要手动迁记录。重装对它几乎无感。
  • 电脑端钉钉有个"开机自启动"， office 电脑建议开着，免得错过打卡提醒；个人电脑可以关掉减少开机负担。
  • 公司电脑如果装了企业管控版，以 IT 部门给的安装包为准，别用个人版覆盖。

05 ｜ WPS Office：文档、表格、PPT
#

🟡 方案整理 · 待实机验证

为什么：打开 .docx / .xlsx / .pptx 这些文件必须有它。WPS 个人版核心功能免费、和 Office 格式兼容，是国内最常用的免费办公套件。

照抄：

  1. 打开 https://www.wps.cn/ → 点「立即下载」→ 选 Windows 版
  2. 双击安装 → 留意勾选框：取消「设为默认办公软件」「推荐安装」之类的选项（除非你确实想用它打开所有文档）
  3. 装完打开，能新建文档就能用

算完成：双击一个 .docx 或 .xlsx 文件能正常打开、编辑、保存。

我试过的：

  • 免费版会有会员推广弹窗，但文档编辑本身不收费。想要完全无广告得开会员，按需决定，不是装机必需。
  • 如果公司用 Microsoft 365，就没必要装 WPS——两套 Office 并存偶尔会出现文件关联冲突。
  • 只想轻量打开文档、不想装大套件：Windows 自带的「记事本」看不了 Word，但可以用浏览器打开 PDF；或者用 LibreOffice（完全免费开源），界面没 WPS 友好。

06 ｜ XMind：画思维导图
#

🟡 方案整理 · 待实机验证

为什么：梳理思路、做方案结构、开会记要点，思维导图比线性笔记清楚。XMind 界面漂亮、上手快，免费版就够日常用。

照抄：

  1. 打开 https://www.xmind.cn/ → 点「下载 App」→ 选 Windows 版
  2. 双击安装 → 一路下一步
  3. 打开后点「新建」→ 选一个结构（比如「思维导图」）→ 中间写主题，按 Tab 加子节点

算完成：能新建一个导图、加几个分支、导出成图片或 PDF。

我试过的：

  • 免费版有限制（2026 年现状）：本地编辑基本够用，但在线导图数量、部分高级导出格式、AI 功能要会员。日常画几张图不用花钱；要大量云同步或高级导出再说。
  • 想完全免费、还想要文件全在本地：用 Freeplane（开源，离线无限张图），缺点界面旧、需要 Java 环境。
  • 已经用 Obsidian 记笔记的话，它的 Canvas 白板也能画类似的图，不用额外装软件。
  • .xmind 文件是完整保存在本地的，重装前把文件备份走就行，软件本身重装无所谓。

07 ｜ 向日葵远程控制：远程回家/回公司
#

🟡 方案整理 · 待实机验证

为什么：人在外面要调家里电脑的文件、帮父母修电脑、或查看公司机器上跑的任务，远程控制工具是刚需。向日葵在国内网络环境下稳定，免费版就够个人用。

照抄：

  1. 打开 https://sunlogin.oray.com/ → 下载 Windows 客户端（个人版免费）
  2. 在被控电脑（家里/公司那台）和主控设备（你手上的电脑或手机）都装上，用同一个手机号注册并登录
  3. 被控电脑里记下「识别码」和「验证码」；主控端输入识别码 → 点「远程控制」→ 输验证码 → 连上

算完成：主控端能看到被控电脑的桌面、能操作鼠标键盘；手机端也能连上。

我试过的：

  • 免费版的边界（2026 年）：不限时长、不限次数，单账号可绑 5 台设备，日常完全够；但晚上 20:00–22:00 高峰期会限速、画质下降，别指望用它看视频或打游戏，传大文件也慢。
  • 想在电脑关机状态下远程唤醒它，需要买向日葵自家的开机插座/开机棒（约几十块），纯软件做不到——这是物理限制。
  • 备选：ToDesk 连接快但免费版每月有 80 小时额度；RustDesk 开源免费、可自建服务器，但配置门槛高，适合有运维能力的用户。
  • 安全提醒：验证码别随便发给别人，用完及时关掉无人值守或改密码。

08 ｜ 迅雷（及更干净的替代）：下载工具
#

🟡 方案整理 · 待实机验证

为什么：下系统镜像、软件安装包、BT 种子和磁力链接时，浏览器自带下载不够用。迅雷协议支持全，但广告、会员推荐、限速是老问题——这一卡同时给一个更干净的选择。

照抄：

如果就用迅雷：

  1. 打开 https://www.xunlei.com/ → 下载 Windows 客户端
  2. 双击安装 → 一步步看勾选框，取消游戏大厅、资讯推送、设为首页这些附加项
  3. 打开后把下载目录改到 D 盘

如果受不了广告，装 Motrix（推荐）：

  1. 打开 GitHub 搜 Motrix，进 Releases 页下载 Windows 安装包（.exe）
  2. 双击安装 → 打开 → 左边「设置」把下载目录改到 D 盘
  3. 把磁力链接或种子文件直接拖进窗口，或点「+ 新建任务」粘贴链接

算完成：能下一个文件，速度正常，进度条走完文件能用。

我试过的：

  • 迅雷免费版对 BT / 磁力有限速、弹窗推会员，这是它这几年的常态。第三方站的"绿色精简版"号称去广告，但来源不明、可能被改过，不建议装——图省事反而引风险。
  • Motrix 基于成熟的 Aria2 内核，支持 HTTP / BT / 磁力，界面干净无广告，日常下载足够，是 2026 年口碑最好的替代之一。要更强的 BT 管理就用 qBittorrent。
  • 下载系统镜像这类大文件，认准官网或官方镜像站，别在下载工具里搜资源——搜到的多半带私货。
  • 法律提醒：只下载你有权获取的内容，别用来下盗版。

09 ｜ VLC：什么格式都能播的播放器
#

🟡 方案整理 · 待实机验证

为什么：遇到 MKV、AVI、FLV、各种编码的视频，系统自带播放器经常打不开或没声音。VLC 免费开源，几乎什么格式都能播，是装机必备的兜底播放器。

照抄：

方式一（推荐，一条命令）：

winget install --id VideoLAN.VLC -e

方式二（官网）：打开 https://www.videolan.org/vlc/ → 点大大的下载按钮 → 选 Windows 64 位 → 双击安装。

装完打开 VLC → 顶部菜单「工具 → 偏好设置 → 界面」→ 语言选「简体中文」（部分版本默认英文）。

算完成：拖一个视频文件进 VLC 窗口，能正常播放、有画面有声音。

我试过的：

  • 当前版本 3.0.24，2026-09-22 发布，是一次安全大更新（修了 130 多个漏洞），如果你机器上还是 3.0.20 或更早，建议升级。winget 装的会自动是最新。
  • VLC 不带任何广告和捆绑，官网是 videolan.org，别在下载站点那些"高速下载器"。
  • 它的能力远不止播放：转格式、截图、串流都能做，但日常记住"打不开的视频丢给 VLC"就够了。
  • 如果只想轻量看本地视频，Windows 商店的「媒体播放器」也够；VLC 的价值在格式兼容广。

10 ｜ 火绒安全软件：杀毒 + 拦弹窗
#

🟡 方案整理 · 待实机验证

为什么：Windows 自带的 Defender 防护已经够用，但国产软件弹窗多，火绒最实用的其实是弹窗拦截。它轻量、无广告、不捆绑，和 Defender 不冲突（火绒注册后 Defender 会自动退到被动模式，不用手动关）。

照抄：

  1. 打开官网 https://www.huorong.cn/ → 点「免费下载」→ 按架构选：绝大多数电脑选 64 位版（x86-64），骁龙本等 ARM 机器选 ARM 版
  2. 双击安装包 → 勾选「我已阅读并接受许可协议」→ 选「极速安装」或点「安装目录」自定义位置
  3. 装完打开 → 左侧「安全工具」→ 找到「弹窗拦截」→ 打开
  4. 「防护中心」→ 把「受控文件夹访问」之类的勒索防护打开（按需）

算完成：右下角托盘有火绒图标；能看到主界面「病毒查杀 / 防护中心 / 访问控制 / 安全工具」四个模块；打开一个带广告弹窗的软件时火绒能拦下来。

我试过的：

  • winget 装不了：winget search 火绒 返回空，官方没向 winget 提交包，网上流传的 winget install HuorongSysdiag 已失效。更别从第三方站下"火绒安装包"——出过冒名 sysdiag.exe 的假货，会静默植入深信服的上网行为管理软件。
  • 卸载必须用官方方式：设置 → 应用 → 已安装的应用 → 卸载火绒，或者装目录下的 uninst.exe。官方明确警告别用第三方强制卸载工具，会导致蓝屏。卸载完重启一次再清残留。
  • 装上后把工作目录、开发工具目录加进「信任区」，否则编译、批量脚本可能被拦。
  • 当前个人版是 6.0，2026 年 6 月更新到 6.0.11.0，兼容 Win11。如果装完遇到无故重启，去 C:\Windows\Minidump 看转储文件是否指向 sysdiag，是的话先卸载换回 Defender 观察一轮，并向官方反馈。
  • 不要装"Defender 关闭工具"（Defender Control 之类）：这类工具本身常被报毒，还容易把系统防护搞成半瘫。
