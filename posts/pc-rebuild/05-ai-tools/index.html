速查表：先看这三款各管什么
#

#工具大白话解释官网怎么装免费
1Ollama把 AI 大模型装在自己电脑里跑，断网也能用ollama.com图形安装包✅ 免费
2Claude Code在终端里跟 AI 说话，让它帮你写代码、改文件claude.ai一行命令 / winget需账号或 API
3CC Switch管好几套 AI 配置，一键切换，不用手改配置文件github.com/farion1231/cc-switch.msi 安装包✅ 开源免费

三者的关系，先理一下，免得装懵：

  • Ollama 是"模型供应商"——在你电脑里提供能对话的 AI 大脑（也可选联网的云端模型）。
  • Claude Code 是"干活的助手"——真正帮你写代码的那个程序。
  • CC Switch 是"开关面板"——当 Claude Code 等工具有好几套账号/接口配置时，用它一键切换。

建议安装顺序：Ollama → Claude Code → CC Switch（开关面板得等被管理的工具装好才有意义）。

2026 年相对旧教程的 3 个变化：

  1. Claude Code 主推"原生安装"，不再必须先装 Node.js；一行 PowerShell 命令搞定，winget 也能装。
  2. Ollama 国内下载模型有解了：配一个 ModelScope 镜像变量，不用再对着龟速的官方源干等；模型默认放 C 盘，建议改到 D 盘。
  3. CC Switch 已到 v4，界面从顶部标签改成左侧栏，网上 v3 的截图对不上；另外有个同名但完全不同的项目（ccswitch.dev，Git worktree 工具），别下错。

前置 ｜ 终端怎么开，Node 要不要装
#

🟡 方案整理 · 待实机验证

为什么：这三款都跟终端（那个打字的黑窗口）打交道。前面 winget 篇已经详细讲过怎么开终端，这里再放一遍，免得你回头翻。

照抄：

  1. 看屏幕左下角的 Windows 图标（四个小方块）→ 点鼠标右键
  2. 菜单里选「终端」或「终端（管理员）」
  3. 看到黑色/深蓝色窗口、光标在闪——这就是终端

三条基本操作：命令敲完必须按 Enter 才执行；复制用 Ctrl + C、粘贴用 Ctrl + V（或窗口里点鼠标右键）；关掉点右上角的 ×。

关于 Node.js：Claude Code 现在主推原生安装，不需要 Node.js。只有你选"npm 安装"那条路时才要先装 Node（见 08 编程环境篇）。这篇按"不用 Node"写。

算完成：能打开终端、能打字、知道按 Enter 执行。

01 ｜ Ollama：把 AI 模型装在自己电脑里
#

🟡 方案整理 · 待实机验证

为什么：Ollama 让你在自己电脑上跑 AI 大模型——免费、断网能用、数据不出本机，适合处理私密内容或纯体验。大白话讲：它就是一个"模型管理器"，帮你把大模型下载好、跑起来，然后你用命令或网页跟它聊天。

照抄：

第一步：安装

  1. 浏览器打开 https://ollama.com/download
  2. 点 Windows 那栏的下载按钮，得到 OllamaSetup.exe（几百 MB）
  3. 双击 → 点 Install → 一路下一步 → 点 Finish
  4. 装完右下角系统托盘会出现一个小羊驼图标，代表后台服务已启动

高级选项：想装到 D 盘，先把安装包放到 D:\AI，在该文件夹地址栏输入 cmd 回车，执行 OllamaSetup.exe /install D:\Ollama。

第二步：配国内加速（国内用户建议做）

模型默认从官方源下载，国内很慢；模型文件默认堆在 C 盘，几个模型就能占几十 GB。两个都改掉：

  1. 按 Win + S 搜「编辑系统环境变量」→ 打开 → 点右下角「环境变量」

  2. 在「系统变量」里点「新建」，加两条：

    变量名变量值作用
    OLLAMA_HF_MIRRORhttps://modelscope.cn用国内魔搭镜像下模型，快很多
    OLLAMA_MODELSD:\OllamaModels把模型存到 D 盘，不撑爆 C 盘

  3. 一路「确定」保存 → 右键托盘小羊驼图标 → Quit 退出，再从开始菜单重新打开 Ollama（环境变量要重启才生效）

第三步：跑第一个模型

打开终端，输入：

ollama --version
ollama run deepseek-r1:8b

第一条看版本号；第二条会自动下载模型（约 5GB，耐心等），下载完直接进入对话界面，打字提问回车就有回答。输入 /bye 退出对话。

算完成：三处都对就算成功——① ollama --version 出版本号；② 终端里能跟模型对话；③ 浏览器打开 http://127.0.0.1:11434，页面显示 Ollama is running。

我试过的：

  • 没显卡也能跑，但慢：8b 这种小模型普通电脑还能应付，别一上来就跑几十 GB 的大模型（会卡到怀疑人生）。显存越大能跑的模型越大。
  • 命令找不到？ 多数是没重开终端——关掉终端重新打开再试；还不行就检查环境变量 PATH 里有没有 %LOCALAPPDATA%\Programs\Ollama。
  • 下载中断不用怕：重新 ollama run 会断点续传，不用从头下。
  • 想要 ChatGPT 那样的网页界面：再装 Open WebUI，浏览器访问 http://localhost:3000。嫌麻烦就先用终端对话。
  • 模型也有许可：只下载你有权使用的模型，别拿它生成违规内容。

02 ｜ Claude Code：让 AI 帮你写代码
#

🟡 方案整理 · 待实机验证

为什么：Claude Code 是 Anthropic 官方出的 AI 编程助手，运行在终端里。你用大白话描述需求，它去读你的项目文件、改代码、跑命令，改之前还会问你同不同意。比在网页里复制粘贴代码高效得多。

照抄：

第一步：安装（推荐原生方式，不用 Node）

右键开始菜单 → 「终端（管理员）」→ 弹出"是否允许"点「是」→ 粘贴执行：

irm https://claude.ai/install.ps1 | iex

如果提示"脚本被禁止运行"，先执行这一条再重试： Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

备选安装方式（三选一即可，别重复装）：

方式命令适合谁
wingetwinget install Anthropic.ClaudeCode -e习惯 winget 的（见 02 篇）
npmnpm install -g @anthropic-ai/claude-code已有 Node.js 的开发者（见 08 篇）
Claude 桌面版官网下载 Claude Desktop，登录后点「Code」标签完全不想碰命令的纯新手

第二步：验证

claude --version
claude doctor

第一条出版本号、第二条诊断无错误，就装好了。记得关掉终端重新开一个再验证，否则可能找不到命令。

第三步：登录（关键，装完还不能直接用）

  1. 终端里输入 claude 回车
  2. 首次运行会让你登录 → 按提示输入 /login
  3. 浏览器会弹出授权页面 → 用你的 Claude 付费账号登录并授权（或用 Console 的 API key）

注意：Claude Code 需要一个 Claude 付费订阅账号，或按量付费的 API key，不是装完就能白嫖。没有账号的话，这一步走不通——可以先跳过本篇，等有账号再回来。

第四步：第一次用

进入你项目文件夹再启动，它才能读到代码：

cd D:\你的项目文件夹
claude

进去后直接用中文说话，比如「这个项目是做什么的？」「帮我加一个登录功能」。它会先展示要改什么，问你同不同意，你确认后才改。输入 /help 看所有命令，/resume 接着上次的对话。

算完成：claude --version 出版本号；claude 能启动并进入对话界面；问一个问题能得到回答。

我试过的：

  • 运行 claude 提示找不到命令：关掉终端重开；还不行检查安装时 PATH 有没有加进去。npm 装的用 npm config get prefix 看全局路径是否落在 C:\Program Files\nodejs（系统保护目录会触发权限问题），改成 npm config set prefix "$env:APPDATA\npm" 后重装。
  • Git 要先装好：Claude Code 靠 Git 管理代码改动。装 Git for Windows 时，在 PATH 那一步选「Use Git from the Windows Command Prompt」，否则它找不到 git（见 08 篇）。
  • VS Code 里用更舒服：在 VS Code 扩展市场装「Claude Code」官方扩展，就能在编辑器里直接呼出它，不用切窗口。
  • 它会改文件、跑命令：重要项目先提交一次 Git（存个档），改坏了能一键退回。别在没备份的目录里让它随便改。
  • 费用：付费账号按订阅用，API key 按量计费，留意用量。

03 ｜ CC Switch：一键切换 AI 工具的配置
#

🟡 方案整理 · 待实机验证

为什么：如果你给 Claude Code 配了不止一套接口（比如官方账号 + 其他合法服务商），传统做法是要手写改 ~/.claude/settings.json 这类配置文件，又麻烦又容易改错。CC Switch 是个 free 开源的小工具，把这些配置做成卡片，点一下就切换，还能统一管理 MCP、提示词、Skills。

⚠️ 别下错：你要找的是 github.com/farion1231/cc-switch / 官网 ccswitch.io。另有一个叫 ccswitch.dev 的 Git worktree 工具，名字像但不是同一个东西。

照抄：

  1. 打开 https://github.com/farion1231/cc-switch/releases
  2. 找到最新版（2026 年 11 月是 v4.0.39），下载 Windows 的 CC-Switch-v-Windows.msi（ARM 电脑选 arm64 版本；想要免安装就下 .zip 便携版）
  3. 双击 .msi 一路下一步；如果点了没反应，右键安装包 → 属性 → 勾选「解除锁定」
  4. 打开后左侧选「Claude Code」→ 点添加供应商 → 按提示填接口地址和密钥 → 保存
  5. 想在几套配置间切换，点对应卡片上的「Switch」即可；系统托盘也能快速切

算完成：软件能打开、左侧能看到 Claude Code、能加一张供应商卡片并切换成功。

我试过的：

  • 只从三个地方下：GitHub Releases、Homebrew（Mac）、官网 ccswitch.io。它要存你的 API 密钥，任何让你付费、登录或装"助手"才能下载的网站都不是官方的。
  • 切换后要不要重启：多数工具要重启终端才生效；Claude Code 支持热切换，不用重启。
  • 它会备份：第一次改写某个工具的配置前，CC Switch 会把原始文件存到 ~/.cc-switch/backups/live-first-write/。所以卸载它也安全——工具会继续用最后一次写入的配置。
  • 它只改连接字段：接口、密钥、模型、API 格式这些会变；你的插件、hooks、MCP、权限设置都不动。
  • v4 界面变了：顶部标签改成左侧栏，还多了 Routing（路由）和 Aggregation（聚合）两种模式。网上 v3 的截图对不上是正常的。普通用户用默认的 Direct（直连）就够。
  • 合规提醒：只配置你有合法使用权的账号和接口。工具本身是中性的，别用它去接来路不明的密钥。
  • WSL 里想用：CC Switch 是个图形桌面程序，服务器/SSH/WSL 环境用不了；社区有单独的 CC Switch CLI 项目，那是另一个东西。

#

一条龙（能自动/脚本装的先装完）
#

在管理员终端里执行（右键开始菜单 → 终端（管理员）→ 点「是」）。两条命令分别装 Claude Code 和 Ollama：

# Claude Code（原生安装，不用 Node）
irm https://claude.ai/install.ps1 | iex

# Ollama（PowerShell 脚本安装）
irm https://ollama.com/install.ps1 | iex

# 装完核对（重开一个终端再跑）
claude --version
ollama --version

手动安装清单（这些要在官网/GitHub 下载，按对应卡片做）：

软件下载地址对应卡片关键动作

CC Switchgithub.com/farion1231/cc-switch/releases03认准官网，别下同名项目
