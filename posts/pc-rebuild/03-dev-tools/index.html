前置 ｜ 打开管理员终端
#

🟡 方案整理 · 待实机验证

为什么：下面有几条命令要在「管理员终端」里跑，普通窗口权限不够。这一步和 winget 篇一样，单独写出来。

照抄：

  1. 看屏幕左下角的 Windows 图标（四个小方块）→ 点鼠标右键
  2. 菜单里选「终端（管理员）」或「Windows PowerShell（管理员）」
  3. 弹出「是否允许此应用更改设备？」→ 点「是」

看到标题带「管理员」字样的黑色窗口、光标在闪，就对了。命令输完必须按 Enter 才执行；粘贴用 Ctrl + V 或在窗口里点鼠标右键。

算完成：能打开带「管理员」字样的终端窗口。

我试过的：多数软件双击安装包就能装，不需要终端；只有 Git、VS Code 这类用 winget 命令装的才需要。分不清就用终端，最省事。

01 ｜ Git + TortoiseGit：给代码存存档
#

🟡 方案整理 · 待实机验证

为什么：Git 是「代码的存档工具」——每改一版就能存一个档，改坏了随时退回去，多人协作也靠它。TortoiseGit 是给 Git 加个「右键菜单」的图形界面，不想敲命令的人用它点鼠标就能提交代码。

照抄（在管理员终端里，一条一条跑）：

winget install --id Git.Git -e
winget install --id TortoiseGit.TortoiseGit -e

装完 TortoiseGit 后，会弹出语言包选择，**选「中文（简体）」**再装一个中文包，右键菜单就变中文了。

然后告诉 Git 你是谁（提交代码时要署名，只做一次）：

git config --global user.name "你的名字"
git config --global user.email "你的邮箱@example.com"

算完成：关掉终端重新打开一个，输入 git --version 能看到版本号；在任意文件夹空白处点右键，菜单里有「Git 克隆…」「Git 提交…」这类选项，就对了。

我试过的：

  • 网络不好时，git 拉代码走代理会快很多。如果需要，执行下面两条（换成你自己的代理端口）：
    git config --global http.proxy http://127.0.0.1:7897
git config --global https.proxy http://127.0.0.1:7897
    不用了就 git config --global --unset http.proxy 取消。
  • TortoiseGit 依赖 Git，必须先装 Git 再装 TortoiseGit，顺序反了会报错。
  • 备选：不喜欢右键菜单风格的话，GitHub Desktop 更适合纯新手，但功能少；老手多用 Fork / SourceTree。

02 ｜ JDK 25：Java 的地基
#

🟡 方案整理 · 待实机验证

为什么：JDK 是「写 Java 必须装的底座」，没有它 Java 程序跑不起来。2026 年最新的长期支持版是 JDK 25。推荐 Eclipse Temurin（免费、无商用授权坑），别下 Oracle 那个——授权条款复杂，以后可能有麻烦。

照抄：

  1. 浏览器打开 https://adoptium.net/
  2. 页面会自动识别系统，选：JDK（版本 25）→ Windows → x64 → .msi 安装包 → 下载
  3. 双击安装，一路「Next」。记住安装路径，默认类似 C:\Program Files\Eclipse Adoptium\jdk-25...
  4. 装完设置环境变量（让系统找得到它）：
    • 右键「此电脑」→ 属性 → 高级系统设置 → 「环境变量」
    • 在「系统变量」里点「新建」：变量名 JAVA_HOME，变量值填上面那个安装路径
    • 找到「Path」→ 编辑 → 新建 → 填 %JAVA_HOME%\bin → 确定

算完成：关掉终端重新打开，输入：

java -version
javac -version

两条都显示 25.x 就对了。

我试过的：

  • 维护老项目可能要 Java 8 / 11 / 21，那就每种各装一个 JDK，用 JAVA_HOME 切换；或者用 Microsoft OpenJDK（微软出的，同样免费）按需装。
  • IntelliJ IDEA 自带一个运行时（JBR），能启动 IDE，但编译 Java 项目仍需要单独装 JDK——别以为装了 IDEA 就不用装 JDK 了。

03 ｜ nvm + Node 24：管住多个 Node 版本（国内加速）
#

🟡 方案整理 · 待实机验证

为什么：Node.js 是跑 JavaScript 的环境，很多项目分别要求 Node 20 / 22 / 24，装一起会打架。nvm 是「Node 版本管理器」，一条命令随时切换。国内下载慢是常态，必须先配镜像。

照抄：

  1. 打开 https://github.com/coreybutler/nvm-windows/releases，下载最新的 nvm-setup.exe（安装版，不要下 zip）
  2. 右键 → 以管理员身份运行，一路 Next。安装路径建议无中文、无空格，比如 D:\nvm
  3. 配国内加速（关键）：打开 nvm 安装目录里的 settings.txt，用记事本在末尾加两行：
    node_mirror: https://npmmirror.com/mirrors/node/
npm_mirror: https://npmmirror.com/mirrors/npm/
    保存即可，不用重启。
  4. 关掉所有终端，重新开一个管理员终端，依次跑：
nvm version
nvm install 24
nvm use 24
  1. 再配 npm 的国内源（这是「装依赖」用的，和上一步的「下 Node 本体」是两回事）：
npm config set registry https://registry.npmmirror.com

算完成：输入 node -v 显示 v24.x、npm -v 显示版本号；输入 npm config get registry 显示 https://registry.npmmirror.com。

我试过的：

  • 如果电脑之前手动装过 Node，必须先卸载干净（控制面板卸载 + 删 C:\Program Files\nodejs），否则 nvm 切换会失效。
  • 常用命令备查：nvm list available（看能装哪些版）、nvm ls（看已装的）、nvm use 22（切到 22）、nvm alias default 24（设默认，以后开终端自动用 24）。
  • 切换版本后全局包会「消失」——这是 nvm 的设计（每个版本独立），重新装一遍即可，或用 nvm install 24 --reinstall-packages-from=22 迁移。
  • 你如果更习惯 fnm，也能用（跨平台、启动快），但 Windows 上 nvm-windows 教程多、更省心；二选一别混装。

04 ｜ VS Code：写 Node.js / 前端工程
#

🟡 方案整理 · 待实机验证

为什么：VS Code 是轻量又强大的代码编辑器，写 Node.js、前端、脚本都顺手。装完再装几个插件就能干活。

照抄（管理员终端一条命令装本体）：

winget install --id Microsoft.VisualStudioCode -e

然后装插件（图形界面操作）：

  1. 打开 VS Code → 左侧图标栏找「扩展」（方块形状，或按 Ctrl + Shift + X）
  2. 搜索框输入名字 → 点「安装」：
插件名作用
ESLint代码规范检查
Prettier - Code formatter自动排版代码
GitLens看代码是谁、什么时候改的
Path Intellisense写路径时自动补全
EditorConfig for VS Code统一团队代码风格

算完成：能打开 VS Code，装好上面几个插件；新建 test.js，写 console.log("hi")，按 F5 或右上方运行按钮，下方终端输出 hi。

我试过的：VS Code 和 Node 是分开的——VS Code 只是编辑器，得先装了 Node（第 3 卡）才能运行 JS。插件别贪多，上面 5 个够用，装多了启动变慢。

05 ｜ IntelliJ IDEA：写 Java 工程
#

🟡 方案整理 · 待实机验证

为什么：写 Java 最主流的集成开发环境（IDE），自动补全、一键运行、调试都强。2026 年注意：官方已把「社区版」和「旗舰版」合并成一个安装包——装完送 30 天 Ultimate 试用，到期后不付费自动变成免费核心版，Java / Kotlin 开发功能都在。

照抄：

  1. 打开 https://www.jetbrains.com/idea/download/
  2. 页面点「Download」，下的是 Windows 统一安装包（当前 2026.3，约 1.1GB）
  3. 双击安装，一路 Next（建议勾选「添加桌面快捷方式」「关联 .java 文件」）
  4. 首次打开：会问是否试用 Ultimate → 想体验就点「试用」，不想就跳过，30 天后自动转免费核心版，不影响 Java 开发

算完成：能新建项目（New Project → 语言选 Java、构建选 Maven 或 IntelliJ、JDK 选第 2 卡装的 25），右键运行 HelloWorld 能看到输出。

我试过的：

  • IDEA 比较吃内存，8G 内存机器建议至少留 3G 给它，否则会卡。
  • 杀毒软件会拖慢它（IDE 不停写索引和缓存）——把安装目录和项目目录加进杀软白名单，别关杀软。
  • 如果你已经用惯 VS Code，也能装「IntelliJ IDEA 的 VS Code 扩展」获得部分 Java 智能提示，但完整体验还是独立 IDE 最好。

06 ｜ Anaconda3 + Python：数据科学与 Python 环境
#

🟡 方案整理 · 待实机验证

为什么：Anaconda 是 Python 的「大礼包」，自带 Python 和几百个科学计算库（pandas、numpy 等），做数据分析、机器学习省去逐个安装的麻烦。

照抄：

  1. 打开 https://www.anaconda.com/download，下载 Windows 版安装包（64-bit）
  2. 双击安装，勾上「Add Anaconda to PATH」之外的默认项即可；安装路径建议无中文
  3. 装完从开始菜单打开「Anaconda Prompt」（一个专用终端，不是普通 cmd）

常用操作（在 Anaconda Prompt 里敲）：

conda create -n myenv python=3.11   # 建一个叫 myenv 的环境
conda activate myenv                # 进入这个环境
conda install numpy pandas          # 装包
conda deactivate                    # 退出环境

算完成：打开 Anaconda Prompt 输入 python --version 显示版本号；conda --version 也有输出。

我试过的（重要）：

  • Anaconda 装完约 3GB，很占空间。如果你只是写普通 Python 项目、不搞数据科学，更推荐 uv（一条命令安装，速度极快、自带锁文件，2026 年新项目主流）或 Miniconda（只有 conda + Python，约 400MB，按需装包）。数据科学 / 深度学习 / 要 CUDA 的场景，仍首选 Anaconda / Miniconda。
  • Anaconda 个人免费，但200 人以上企业商用需授权——公司机器注意合规。
  • 国内下载 conda 包慢的话，配清华镜像（搜索「Anaconda 清华镜像」按站内说明配置）。

07 ｜ Tiny RDM：可视化管理 Redis
#

🟡 方案整理 · 待实机验证

为什么：Redis 是个内存数据库，命令行看数据很麻烦。Tiny RDM 是免费的图形界面工具，点点鼠标就能看、改 Redis 里的数据，轻量、启动快、中文友好。

照抄：

  1. 打开 Tiny RDM 官网或 GitHub 发布页，下载 Windows 安装包（选 x64）
  2. 双击安装，一路 Next
  3. 首次打开 → 点「新建连接」→ 填 Redis 地址（本地开发一般是 127.0.0.1，端口 6379）、密码（如果设了）→ 保存 → 双击连接

算完成：连接成功后，左侧列出数据库（DB0、DB1…），右侧能看到键值对，就对了。

我试过的：

  • 连接远程 Redis 失败，先查三样：防火墙是否放行 6379 端口、Redis 配置是否允许远程连接、是否要密码。
  • 中文乱码：在「首选项 → 数据显示」把编码设为 UTF-8。
  • 备选：Another Redis Desktop Manager（功能更全，JSON 可视化、SSH 隧道强，社区活跃）；要极致稳定或生产环境排查，备一个官方 RedisInsight。日常轻量用 Tiny RDM 足够。

08 ｜ DBeaver 社区版：数据库管理（Navicat 平替）
#

🟡 方案整理 · 待实机验证

为什么：可视化管理 MySQL / PostgreSQL / SQL Server 等数据库——写 SQL、看表、导数据都靠它。Navicat 太贵（旗舰版上千元），免费的 Premium Lite 又限制多，DBeaver 社区版是 2026 年公认最稳的全能免费替代。

照抄：

  1. 打开 https://dbeaver.io/download/，下载 Community（社区版） 的 Windows 安装包（当前 26.2.5）
  2. 双击安装，一路 Next
  3. 首次打开 → 点「新建数据库连接」→ 选数据库类型（如 MySQL）→ 填地址、端口、用户名、密码 → 测试连接成功 → 完成

算完成：左侧能展开数据库、看到表，能执行 SELECT * FROM 表名 出结果，就对了。

我试过的：

  • DBeaver 基于 Java，界面功能多但偏「重」，第一次打开会稍慢。
  • 只管 MySQL、想要更轻快的：用 HeidiSQL（Windows 专用、启动飞快）；喜欢现代简洁界面的：Beekeeper Studio 社区版。
  • JetBrains IDE 用户、非商业用途：DataGrip 有非商业授权，和 IDEA 风格统一。
  • 各数据库官方工具（MySQL Workbench、pgAdmin）也免费，但只管自家库；多库混用还是 DBeaver 省事。

09 ｜ Apifox：调试接口 + API 文档
#

🟡 方案整理 · 待实机验证

为什么：调接口（测试后端给的接口能不能用）、写 API 文档、造假数据（Mock）一体化。2026 年 3 月起 Postman 免费版限制为 1 人，Apifox 核心团队协作功能仍免费、全中文，是当下最合适的替代。

照抄：

  1. 打开 https://www.apifox.cn/，下载 Windows 客户端（当前 2.8.52）
  2. 双击安装，一路 Next，注册/登录账号（免费）
  3. 新建项目 → 新建接口 → 填请求地址和方法（GET/POST）→ 点「发送」，看返回结果

算完成：能发出一个请求、看到服务器返回的数据；能导出一份 API 文档。

我试过的：

  • 兼容 Postman 的脚本语法，从 Postman 迁移：在 Apifox 里选「导入 → Postman」，把导出的数据导进来即可。
  • 2026 年新增了 MCP / AI 能力（能让 Claude Code、Cursor 等直接读接口文档、跑测试），如果后续玩 AI 编程会有用。
  • 备选：只想要个轻量请求工具、不搞团队协作 → Bruno（离线、Git 友好）或 VS Code 里的 Thunder Client 插件。

常见问题
#

你会看到这说明怎么办
winget 提示「无法识别的命令」终端不对或拼写错用管理员终端；winget 全小写，命令照抄
装 Git 后右键没菜单TortoiseGit 没装或装反了顺序先装 Git 再装 TortoiseGit，装完重启资源管理器
java -version 不识别环境变量没生效确认 JAVA_HOME 和 Path 填对，关掉终端重开
nvm 切换版本后 node -v 还是旧的旧 Node 没卸干净按第 3 卡卸载旧 Node，或用管理员终端重跑 nvm use
npm 装包很慢没配国内源npm config set registry https://registry.npmmirror.com
IDEA 提示内存不足内存给少了设置里调大堆内存，或关掉其他占内存的程序
数据库连不上地址/端口/密码错，或服务没启动先确认数据库服务在运行，再核对连接参数
装完软件开始菜单找不到图标被折叠了点开始菜单搜软件名；或安装时勾选了「创建快捷方式」的选项

一条龙（能自动装的先装完）
#

在管理员终端里执行（右键开始菜单 → 终端（管理员）→ 点「是」）。这三款有可靠的安装包标识，一条命令搞定：

# Git / TortoiseGit / VS Code
winget install --id Git.Git -e
winget install --id TortoiseGit.TortoiseGit -e
winget install --id Microsoft.VisualStudioCode -e

# 装完核对
git --version
code --version
