Claude Code 是什么
#

Claude Code 是 Anthropic 推出的终端 AI 编程代理（Agentic Coding Tool）。它不是一个代码补全插件，而是一个能在终端里理解整个代码库、自主规划、跨文件修改、运行测试、提交 PR 的智能协作者。

与 GitHub Copilot、Cursor 等"编辑器内补全"工具不同，Claude Code 的定位是终端优先的代理式开发——你描述目标，它拆解步骤、执行修改、验证结果。

截至 2026 年，Anthropic 内部的大量代码已由 Claude Code 编写，工程师的角色从"写代码"转向"架构设计 + 编排代理"。

维度说明
核心能力理解代码库、跨文件编辑、运行命令、自主执行多步骤任务
运行环境macOS / Linux / Windows 终端 + VS Code & JetBrains 插件
模型支持Claude Opus 4.6 / Sonnet 4.6 / Haiku 4.5
定价模式Pro $20/月、Max $100-$200/月、Team/Enterprise
上下文窗口标准 200K tokens（Sonnet 5 支持 1M tokens）

为什么选 Claude Code：核心差异化
#

1. 真正的代理循环（Agentic Loop）
#

Claude Code 不是"你说一句我改一行"，而是你说一次、它跑一个完整循环：收集上下文 → 规划步骤 → 执行修改 → 验证结果 → 继续迭代。一个指令可以链式执行几十个工具调用，中间自动纠错。

# 一句话触发完整流程
claude "给 auth 模块写测试，跑测试，失败的地方修掉"

背后发生了什么：读取 auth 模块代码 → 分析现有测试覆盖率 → 编写新测试 → 执行 npm test → 检查失败日志 → 修复 bug → 重新运行 → 直到全部通过。

2. 终端原生，连接一切
#

因为是 CLI 工具，Claude Code 可以直接使用你本地的所有命令行工具——git、docker、npm、curl、数据库客户端……没有中间层，没有封装限制。你可以 pipe 日志给它、在 CI 中用 -p 模式做自动化、链式调用：

tail -200 app.log | claude -p "检查是否有异常"
git diff main --name-only | claude -p "review 这些变更的安全性"

3. 多代理并行 + 自定义
#

Claude Code 支持生成多个子代理同时处理不同子任务，由"领导代理"协调分配和合并结果。同时提供了完整的 Agent SDK，你可以构建自己的专用代理。

日常开发中，CLAUDE.md 文件存储项目级别的持久指令——编码规范、常用命令、架构说明，Claude Code 每次启动自动读取。

4. 全平台无缝切换
#

在终端开始、浏览器继续、手机上收结果——Claude Code 的会话不绑定单一界面：

  • 终端：完整 CLI 体验
  • VS Code / JetBrains：IDE 插件
  • Desktop App：可视化 Diff 审查
  • Slack：@Claude 从聊天直接发 PR
  • Remote Control：手机或浏览器远程控制终端会话

5. 生态能力：Routines、Hooks、MCP
#

  • Routines：配置一次性或周期性自动化任务（早间 PR review、��间 CI 失败分析、每周依赖审计），运行在 Anthropic 托管基础设施上
  • Hooks：每次文件编辑前后自动执行自定义指令（如 eslint --fix）
  • MCP 协议：通过 Model Context Protocol 连接 GitHub、数据库、API 等外部服务

适合谁
#

  • 需要处理复杂多文件重构的开发者
  • 想用自然语言描述需求、让 AI 拆解执行的产品经理或设计师
  • 追求终端工作流不离开命令行的极客
  • 需要自动化日常开发任务的工程团队

不适合：只想要行内代码补全（Copilot 更轻量）、对 AI 生成代码有严格合规要求的场景。

快速开始
#

# macOS / Linux
curl -fsSL https://claude.ai/install.sh | sh

# 启动
claude

# 直接提问
claude "介绍一下这个仓库的结构"

# 恢复上次会话
claude --resume
